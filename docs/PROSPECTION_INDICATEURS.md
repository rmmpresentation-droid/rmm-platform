# Indicateurs de prospection

La liste des prospects affiche des compteurs cliquables et reste accessible aux mêmes rôles et selon les mêmes droits qu'auparavant. Le Kanban de suivi reste uniquement dans chaque fiche prospect ; il n'est plus proposé dans la liste générale. Aucune fiche ni historique n'est supprimé.

Les compteurs portent sur toutes les fiches reçues par l'utilisateur courant, avant le filtre de recherche : total ; non commencés (statut vide) ; en cours (premier contact, prise de rendez-vous, présentation nouvelle ou historique, closing) ; consommateurs ; candidats networkers ; sans commande. Un clic filtre la liste ; la recherche s'ajoute au filtre. Les statuts historiques de présentation sont comptés en cours, sans transformation des données. Les comptes n'impliquent ni vente, ni chiffre d'affaires, ni taux de conversion.

La vérification visuelle dans un navigateur connecté et les tests sur PostgreSQL réel restent nécessaires avant validation.
